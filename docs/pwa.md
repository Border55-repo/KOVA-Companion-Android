# Kova Companion webapp

[Åpne webappen](https://border55-repo.github.io/KOVA-Companion-Android/)

På iPhone: åpne i Safari, velg Del → Legg til på Hjem-skjermen, start fra
ikonet og aktiver varsler i appen.

På Android: åpne i nettleseren, velg Installer app eller Legg til på
startskjermen, start fra ikonet og aktiver varsler.

Bridge leverer aktivitetsendringer og personlige påminnelser via Web Push.
Varsler krever et aktivt abonnement og enhetens tillatelse. Status for
levering kan ses i adminpanelet; mottak på fysisk telefon må kontrolleres
separat.
