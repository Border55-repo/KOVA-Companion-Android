# Personvernerklæring – Kova Companion

Sist oppdatert: 9. oktober 2026

Kova Companion er en uoffisiell webapp som viser offentlig tilgjengelige
KOVA-aktiviteter. Den kan installeres fra nettleseren på iPhone og Android.

Webappen henter offentlig aktivitetsinformasjon fra KOVA via Kova Bridge.
Valg, notater og varselhistorikk lagres på enheten. For Web Push lagres
tekniske abonnementsdata og varselvalg i Firebase slik at varsler kan sendes.
Push-leverandøren behandler nødvendige tekniske data for leveringen.

Appen ber ikke om Røde Kors-passord, Okta-konto, innloggingscookies eller
private KOVA-data. Den bruker ikke Firebase Analytics. Utvikleren selger
ikke personopplysninger.

Lenker til KOVA og GitHub åpner eksterne tjenester med egne personvernvilkår.
Kova Companion er ikke en offisiell Røde Kors- eller KOVA-app.

Spørsmål kan tas via [GitHub Issues](https://github.com/Border55-repo/KOVA-Companion-Android/issues).
