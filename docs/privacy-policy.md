# Personvernerklæring – KOVA Companion

Sist oppdatert: 23. september 2026

KOVA Companion er en uoffisiell Android-app som viser offentlig tilgjengelige kalenderdata fra KOVA.

## Data appen bruker

Appen henter offentlig kalenderinformasjon fra KOVA og fra KOVA Companion Bridge. Dette kan blant annet være dato, klokkeslett, aktivitetstype og offentlig beskrivelse.

Valg som favoritter, valgt hjelpekorps, filtre, påminnelser og lokal aktivitetscache lagres lokalt på enheten.

## Varsler

Appen bruker Firebase Cloud Messaging (FCM) for pushvarsler. Firebase kan automatisk behandle teknisk informasjon som appversjon, Firebase-installationsdata og enhets-/appmetadata som er nødvendig for å levere tjenesten.

KOVA Companion bruker ikke Firebase Analytics og eksporterer ikke meldingsleveringsmålinger til BigQuery.

## Innlogging og private KOVA-data

Appen ber ikke om eller lagrer Røde Kors-passord, Okta-konto, innloggingscookies eller private KOVA-data.

## Deling og salg

Utvikleren selger ikke personopplysninger. Appen sender ikke favoritter eller lokale appinnstillinger til en egen brukerdatabase.

## Eksterne tjenester

Appen kan åpne lenker til KOVA og GitHub i nettleseren. Disse tjenestene har egne personvernvilkår.

## Uoffisiell app

KOVA Companion er ikke en offisiell Røde Kors- eller KOVA-app.
