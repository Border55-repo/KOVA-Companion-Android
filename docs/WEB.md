# Kova Companion publisering

- Webapp: https://border55-repo.github.io/KOVA-Companion-Android/
- Admin: https://border55-repo.github.io/KOVA-Companion-Android/admin/
- Kilde: `pwa/`
- Tester: `node --test pwa/tests/*.test.mjs`
- Publisering: `.github/workflows/companion-web.yml`

Kova Companion er et selvstendig webprodukt for iPhone og Android.
Den native Android-appen og APK-publisering er avsluttet. Bridge og
Cloudflare-dispatcheren støtter webappen. URKH er et eget produkt.

Den gamle KlarX-adressen er en migreringslenke. Brukere som installerte
webappen fra den adressen, kan måtte legge den til på Hjem-skjermen på nytt
fra adressen ovenfor og aktivere varsler der.
