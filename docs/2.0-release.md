# KOVA Companion 2.0

KOVA Companion 2.0 samler 1.x-arbeidet i en stabil Android-, PWA- og Bridge-plattform.

## Plattform

- Android-app med signert APK/AAB og automatisk oppdateringsmanifest
- installérbar iPhone/web-PWA med automatisk cacheoppdatering
- KOVA Bridge med eksplisitt `apiVersion: 2.0`
- capability discovery i Bridge-index og health
- bakoverkompatible JSON-snapshots
- Firebase Cloud Messaging for Android
- Web Push for PWA
- KOVA Admin for drift, synk og helse

## Brukerfunksjoner

- kommende vakter først
- Mine vakter med stabile favoritter
- lokale notater
- tilpassbare påminnelser
- kalender og deling
- flere korps, korpssøk og favorittkorps
- varselfiltre, stille perioder og varselhistorikk
- detaljvisning med sted/kontakt når KOVA-data inneholder dette
- offline fallback og automatisk gjenoppretting
- dark mode, responsiv layout og tilgjengelighetsforbedringer

## Robusthet

Bridge 2.0 annonserer støttede egenskaper i stedet for at klientene må anta backend-funksjoner. Dette gjør det mulig å utvide backend gradvis uten å bryte eldre klienter.

Snapshot:
- `apiVersion: 2.0`
- `schemaVersion: 3`

Index:
- `apiVersion: 2.0`
- `schemaVersion: 4`
- `capabilities`

Health:
- `apiVersion: 2.0`
- `schemaVersion: 3`
- `capabilities`

## Releasekrav

2.0.0 skal ikke regnes som publisert før:
- Android unit tests er grønne
- Android lint er grønn
- Bridge unit tests er grønne
- signert APK og AAB er bygget
- APK-signaturen er verifisert
- GitHub Release er publisert
- `app-update.json` peker på 2.0.0
- PWA Quality er grønn og GitHub Pages er publisert

Google Play intern/lukket test er et separat distribusjonstrinn og avhenger av at Play Console/servicekonto har tilgang til appen.
