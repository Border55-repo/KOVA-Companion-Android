# Play Store-skjermbilder

Bruk ekte Android-build av KOVA Companion. Ikke bruk genererte bilder som fremstilles som faktisk app-UI.

Ta minst disse motivene:
1. Forside med Neste vakt / Denne uka
2. Mine vakter
3. Korpsvalg og søk
4. Vaktdetaljer med kalender/notat
5. Varselinnstillinger
6. Dark mode

Kontroller før opplasting:
- ingen personopplysninger eller private data
- ingen testpassord
- ingen adminskjerm med sensitiv backendinfo
- lesbar tekst
- samme appversjon som Play-build
