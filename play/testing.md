# Google Play testplan

## Intern test

Minimumskontroll:
- installer fra Play-testlenken på minst én Android-enhet
- oppgrader fra forrige KOVA Companion-versjon
- velg og søk etter hjelpekorps
- følg minst to hjelpekorps
- verifiser push fra begge
- test ny, endret og fjernet aktivitet
- test stille periode
- test Mine vakter og påminnelse
- test lokal note
- test kalender
- slå av nett og åpne sist lagrede aktiviteter
- slå på nett og kontroller automatisk synk
- kontroller oppdateringssjekk
- kontroller dark mode og stor tekst

## Lukket test

Gjenta intern test med flere enheter/brukere og samle:
- enhetsmodell
- Android-versjon
- installasjon/oppgradering OK
- push OK
- offline OK
- feil eller UX-kommentar

## Godkjenningskriterium

Ingen kritiske feil i installasjon, synk, push, Mine vakter eller oppdatering før build flyttes videre.
